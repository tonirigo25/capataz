# IP chain register

The public repository records the process only. Names, signatures, contracts and
identity data belong in `docs/data-room/private/legal/ip-chain/`, which is ignored.

Required private row fields: record ID; human author; employer/contractor status;
contribution period and paths; AI assistance disclosure; third-party inputs;
agreement/assignment reference and date; signer authority; exceptions; reviewer;
SHA-256 of the signed evidence.

Statuses are `UNVERIFIED`, `VERIFIED` or `EXCEPTION`. Release requires no
unresolved exception for the release scope. Current legal verification remains
external; this file does not invent an assignment.
