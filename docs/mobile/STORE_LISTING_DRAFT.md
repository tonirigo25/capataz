# Orqena mobile store listing — draft

Status: `NOT_SUBMITTED`; requires legal, brand, privacy, device and store review.

Orqena is the mobile client for the same private-beta business workspace served by the configured web backend. It helps construction, renovation and installation teams review clients, visits, quotes, work, expenses, invoices and collections. Sensitive actions remain subject to server authorization and human confirmation.

The app requires network access. Availability of billing, email, AI, fiscal or storage integrations depends on the company's approved backend configuration; the listing must not imply that a disabled provider is live. No publication date, store approval, certification, offline capability or device compatibility result is claimed by this draft.

Privacy and support links must use the approved release domain.
