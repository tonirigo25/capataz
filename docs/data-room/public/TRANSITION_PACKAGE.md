# Transition package

Technical handover includes repository/branch map, exact release SHA, migration
inventory, artifact checksums, SBOM/licenses, CI configuration, architecture/ERD,
runbooks, known issues, external gates and a supervised restore/release exercise.

Acceptance requires a clean-clone build, isolated database validation, receipt of
the signed asset schedule, access transfer without sharing secrets in documents,
and acknowledgement of every `READY_FOR_EXTERNAL_INPUT` gate.

Included support hours, response windows, price, personnel and calendar dates are
commercial decisions and remain `HANDOVER-COMMERCIAL-001`. No number is invented
in this repository.
