# REFERENCIAS VISUALES CANÓNICAS

El paquete incluye cuatro SVG que muestran directamente las imágenes aprobadas desde URLs permanentes y dos scripts para descargar los PNG exactos.

## Orden de prioridad

1. `01_PORTADA_FINAL_OSCURA.svg` / `.png`
   - Portada, hero, proporciones y dirección principal.

2. `02_PORTAL_INTERNO_CLARO.svg` / `.png`
   - Portal, dashboard, sidebar oscura, contenido claro y panel IA.

3. `03_MENU_MOVIL_PLANTILLAS.svg` / `.png`
   - Mega menú, móvil, vistas internas, factura y selector de plantillas.

4. `04_PRESENTACION_GENERAL.svg` / `.png`
   - Visión global, pops IA y composición complementaria.

## Descargar los PNG exactos

Windows:

```powershell
powershell -ExecutionPolicy Bypass -File .\DESCARGAR_PNG.ps1
```

macOS/Linux:

```bash
bash ./descargar_png.sh
```

También puede abrirse `INDEX.html` para ver las cuatro referencias en navegador.

No copiar marcas, clientes, cifras ni datos ficticios. Usar composición, jerarquía, densidad y patrones de interacción.
