# Contributing

This is a private proprietary project. Contributions require an approved issue,
least-privilege repository access, review by CODEOWNERS, passing CI and an IP
record identifying the human author, employer/contract relationship and any AI
assistance.

Do not submit customer data, credentials, contracts, private keys, production
exports or third-party material without a documented license. Synthetic fixtures
must use reserved domains and deliberately invalid identifiers.

An external contribution is not accepted merely because a pull request is
merged. The authorized rights holder must archive the applicable employment,
contractor or contribution agreement in the private legal data room. The
repository stores only a non-secret reference and status.

Security-sensitive changes require tenant-negative tests, human confirmation
for irreversible effects and an append-only decision/evidence record.
